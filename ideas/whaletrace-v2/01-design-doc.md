# WhaleTrace v2 — 產品設計文件

## 一行摘要

**鯨魚共振訊號雷達**：自動偵測機構合計買入超過 1 億美元、且內部高管同步跟進買入的股票，幫助使用者一眼看見華爾街真正的大錢流向。

---

## 問題 / 目的

市面上有 SEC 申報資料（EDGAR）、有財經新聞、有各種美股分析工具，但**沒有一個工具做這件事**：

> 同一支股票，A 機構買 6000 萬、B 機構買 5000 萬 → 合計破億。同時間，這家公司的高管自己也掏錢買進。

這是「鯨魚共振」——機構的錢和內部人的錢同時進場。現有工具要手動交叉比對才能發現，本產品自動算好、排好、推到使用者面前。

---

## 產品哲學

- **只呈現事實，不給投資建議**。WhaleTrace 是數據雷達，不是投顧。
- **數據密度高，不等於難讀**。彭博終端機的專業感，但一人創業者能看懂。
- **被動追蹤，主動推播**。不用每天打開，你關注的股票有動靜，Telegram/Line 自動通知。

---

## 目標使用者

1. **自己**（第一使用者）：每天掃共振訊號，做投資決策參考
2. **公開上線後**：對美股內部人交易有興趣的散戶 / 獨立交易者
3. 需要註冊登入，有個人關注清單

---

## 核心概念：鯨魚共振訊號

```
條件 1：同一支股票，機構合計買入金額 > $100M（不限一家機構）
條件 2：同一支股票，內部高管（C-level / Director / Chairman）有買入紀錄
條件 3：兩者在合理時間窗內發生（預設 30 天）

→ 觸發「鯨魚共振訊號」
```

## 主要使用者流程

### 流程 A：每日快速掃描（核心）
1. 打開 WhaleTrace → 首頁混合儀表板
2. 看到「**共振訊號排行榜**」——按訊號強度排序
3. 每列顯示：股票代號、公司名、機構總買入金額、機構清單（各家金額）、內部人買入人數、訊號日期
4. 點進去 → 股票詳情頁

### 流程 B：股票詳情頁
1. 信心分數環形圖（已有 Phase 2）
2. **機構持股區域**：表格列出每家機構名稱、持股數、市值、變動方向
3. **內部人時間軸**（已有 Phase 2）
4. **共振歷史**：這支股票過去是否有過共振訊號？每次訊號後 3/6/12 個月報酬率
5. **股價走勢圖**（Phase 5 新增）

### 流程 C：關注 + 推播
1. 在任何頁面對股票點「關注」
2. 關注後：這支股票有任何機構或高管買入 → Telegram/Line 推播（不限金額）
3. 關注清單頁可管理、移除
