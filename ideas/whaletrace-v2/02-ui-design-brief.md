# WhaleTrace v2 — UI 設計簡報

## 目的

讓 WhaleTrace 從「功能清單」變成「可以想像的畫面」。彭博終端機的專業感 + 暗色主題 + 數據密度高。

---

## 產品感受

| 屬性 | 方向 |
|---|---|
| 密度 | **高**——每吋螢幕都有資訊，不留白 |
| 色調 | 暗色為主（已建立 Design Token），綠色=買入，紅色=賣出，紫色=訊號 |
| 字體 | Inter（UI）+ JetBrains Mono（數據/代號） |
| 動畫 | 極簡——fade-in 進場，不花俏 |
| 互動 | 表格為主、卡片為輔、hover 展開細節 |
| 專業感 | 數字對齊（tabular-nums）、金額格式化、無 emoji 裝飾（除訊號圖示） |

---

## 視覺方向

已建立的 Design Token 完全適用：

| Token | 用途 |
|---|---|
| `--bg-canvas` (#08090a) | 頁面背景 |
| `--bg-surface` (#0f1011) | 卡片/表格背景 |
| `--bg-elevated` (#191a1b) | 重點區塊 |
| `--green-primary` (#10b981) | 買入/正向 |
| `--red-primary` (#ef4444) | 賣出/負向 |
| `--signal-purple` (#8b5cf6) | 共振訊號（產品核心色） |
| `--amber-primary` (#f59e0b) | 10b5-1 中性 |
| `--text-primary` (#f7f8f8) | 主文字 |
| `--text-secondary` (#d0d6e0) | 次文字 |
| `--text-tertiary` (#8a8f98) | 輔助文字 |
| `--text-muted` (#62666d) | 最弱文字 |

## 狀態設計

| 狀態 | 處理方式 |
|---|---|
| **載入中** | Skeleton（card/text/chart 三種 variant） |
| **空狀態** | 每個清單有專屬 icon + 引導文字 |
| **錯誤** | EmptyState + 錯誤訊息 + 重試按鈕 |
| **首次使用** | 首頁顯示引導：「尚無共振訊號，試著搜尋你感興趣的股票」 |
| **未登入** | 關注清單/設定頁顯示登入提示 + 登入按鈕 |

## 實作交接備註

1. 首頁是第一個要改的——目前 FeedPage 只有交易動態牆，需要升級成三段式儀表板
2. 共振訊號的計算邏輯先在 n8n 跑定時任務，透過 API 提供給前端
3. Telegram 推播用既有樹洞 Bot 的經驗（HTTP Request → Telegram Bot API）
4. 彭博感 = 表格多、字小、行距窄、數字對齊、無多餘裝飾
