# 內部人交易 + 機構持倉儀表板 — 產品簡報

## 一句話
美股內部人跨公司買股追蹤 + 機構重倉排行，Bloomberg 風格的篩選器儀表板。

## 核心使用者 + 問題
- **使用者**：自己 + 少數封測朋友
- **問題**：想知道「聰明錢」在做什麼——內部人買了哪家、機構押了哪家

## 主要工作流程
1. 打開儀表板 → 看到兩大區塊
2. **區塊 A**：今日內部人跨公司買股列表（誰買了誰、金額、歷史脈絡）
3. **區塊 B**：機構目前重倉排行（哪些公司被最多機構重押）
4. 點擊任一項目 → 展開細節面板（10 年內部人歷史 + Morningstar 級財報 + 技術線圖）

## 核心功能（優先級排序）
1. 內部人 Form 4 跨公司買股列表（爬 SEC EDGAR）
2. 10 年內部人交易歷史（含買/賣標註）
3. 機構 13F 重倉排行
4. Morningstar/Gurufocus 級基本面數據
5. 技術線圖（Lightweight Charts）

## 產品氣質
- **主畫面**：Bloomberg 終端機風格（黑底、琥珀色強調、高資訊密度）
- **篩選/表格區**：Finviz 風格（排序、篩選、熱力圖）
- 鍵盤操作 + 滑鼠點擊雙支援

## 資料來源
- 全部爬蟲（SEC EDGAR、13F filings、財報網站）
- 使用 scrapling-web-scraper + sec-edgar-insider-trades 技能

## 平台
- MVP：純網頁（桌面為主）
- 未來：手機適配

## 技術棧（已確認）
| 項目 | 選擇 |
|------|------|
| 前端 | React + Vite + TypeScript + Tailwind v3 |
| 資料 | 爬蟲 → JSON 檔（直接 import，免後端） |
| 圖表 | Lightweight Charts（TradingView 同款） |
| 部署 | GitHub Pages |
| 風格 | Bloomberg 黑底主畫面 + Finviz 篩選表 |

## 底線
- **無底線**——產品可以自由演化，不被預設框架綁住
